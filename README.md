# ScRNA-sequencing-Malika-

In order to run the code files, R (and optionally RStudio) will need to be installed first. Refer to this links for more details: https://rstudio-education.github.io/hopr/starting.html
To run the files in jupyter notebook, this will also have to be downloaded and connected to R.
- To download Jupyter notebook, follow this link: https://jupyter.org/install
- To connect it to your downloaded R, change the kernel to R.
- Then open your R or RStudio console and enter: install.packages('IRkernel')
- Then register the kernel so jupyter can find it by running this in the console: IRkernel::installspec()
- Then launch jupyter notebook on your device:
  - Open your terminal or command prompt, navigate to your project folder using cd
  - Type: jupyter notebook

The code files on github will need to be downloaded to run. In order to download the packages needed for this pipeline, please refer to the install packages code file.
